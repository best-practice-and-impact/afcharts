# Analysis Function colour palettes

A list grouping colours into palettes. Note that the use of the `main`,
`main2` and `main6` colour palettes is deprecated. Please use
`categorical` and `categorical2` instead, which give access to the same
colours.

## Usage

``` r
af_colour_palettes
```

## Format

A character list
